# Vue 3 + TypeScript + Vite + Vue Router + Pinia

一个使用 Vue 3 + TypeScript + Vite + Vue Router + Pinia 搭建的 SSR 模版项目

# 如何使用

安装

```
pnpm install
```

执行开发环境

```
pnpm run dev
```

执行生产环境

```
// 先打包
pnpm build

// 再启动服务
pnpm run prod
```
